# MNIST reports (`reports/Latex_report/v1_mnist/`)

| Folder | Report | What it covers |
|---|---|---|
| [`p1_model_training_baseline/`](p1_model_training_baseline/README.md) | `cnn_baseline_report.pdf` | Phase 1: data split, LeNet-5, test results, embeddings |
| [`p2_som_training_visualization/`](p2_som_training_visualization/README.md) | `som_cluster_error.pdf` | Phase 2: SOM training, cluster analysis, error patterns |
| [`p3_novelty_detection/`](p3_novelty_detection/README.md) | `novelty_detection.pdf` | Phase 3: QE and U-Matrix novelty detection against SVHN and the baselines |
| [`p4_guided_retraining/`](p4_guided_retraining/README.md) | `guided_retraining.pdf` | Phase 4: hard examples, curriculum, targeted augmentation, SOM re-analysis |
| [`Final_report/`](Final_report/README.md) | `final_report.pdf` | The whole MNIST study in one report |

Figures come from `outputs/v1_mnist/` and are copied into each report's `fig/` folder. Diagrams are drawn in draw.io: the `.drawio` source and the exported `.drawio.svg` are kept together, and the report includes a PDF export.
