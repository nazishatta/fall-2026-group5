# `novelty_after_retraining` (Fashion-MNIST)

The code for this step is shared by both datasets and lives in [`src/v1_mnist/component/p4_guided_retraining/novelty_after_retraining/`](../../../../v1_mnist/component/p4_guided_retraining/novelty_after_retraining/).
Fashion-MNIST runs it with the settings in [`../../configs/`](../../configs/), so nothing is copied here.

The step produces novelty scores on the retrained networks. Its results go to `outputs/v1_fashion_mnist/p4_guided_retraining/novelty_after_retraining/`.
