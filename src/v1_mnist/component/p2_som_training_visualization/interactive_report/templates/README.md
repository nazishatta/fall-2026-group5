# Report templates (`src/v1_mnist/component/p2_som_training_visualization/interactive_report/templates/`)

The HTML page, styles and JavaScript that `html_report.py` fills with the SOM data to make the interactive report. The scripts in `js/` load in a fixed order (see `js/README.md`).

## Folders

| Folder | What is inside |
|---|---|
| [`js/`](js/README.md) | These files hold the browser-side code of the interactive SOM report. |

## Files

| File | What it is |
|---|---|
| `report_page.html` | The page template the report code fills in. |
| `report_style.css` | The page's styles. |
