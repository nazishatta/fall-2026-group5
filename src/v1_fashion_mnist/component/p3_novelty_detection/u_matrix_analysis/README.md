# `u_matrix_analysis` (Fashion-MNIST)

The code for this step is shared by both datasets and lives in [`src/v1_mnist/component/p3_novelty_detection/u_matrix_analysis/`](../../../../v1_mnist/component/p3_novelty_detection/u_matrix_analysis/).
Fashion-MNIST runs it with the settings in [`../../configs/`](../../configs/), so nothing is copied here.

The step produces U-Matrix novelty scores and where outside images land on the map. Its results go to `outputs/v1_fashion_mnist/p3_novelty_detection/u_matrix_analysis/`.
