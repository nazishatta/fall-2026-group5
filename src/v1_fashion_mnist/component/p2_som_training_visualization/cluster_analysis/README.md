# `cluster_analysis` (Fashion-MNIST)

The code for this step is shared by both datasets and lives in [`src/v1_mnist/component/p2_som_training_visualization/cluster_analysis/`](../../../../v1_mnist/component/p2_som_training_visualization/cluster_analysis/).
Fashion-MNIST runs it with the settings in [`../../configs/`](../../configs/), so nothing is copied here.

The step produces best-matching neurons, class purity against a label-shuffled baseline, and class maps. Its results go to `outputs/v1_fashion_mnist/p2_som_training_visualization/cluster_analysis/`.
