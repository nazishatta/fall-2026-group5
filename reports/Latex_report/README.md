# LaTeX reports (`reports/Latex_report/`)

One folder per dataset version. Each report folder holds its `.tex` source, `File_Setup.tex` (packages and page style), `references.bib`, a `fig/` folder with the figures it uses (PDF only), and the compiled PDF.
