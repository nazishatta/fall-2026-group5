# LaTeX reports (`reports/Latex_report/`)

One folder per dataset version, plus one for the report that covers both. Each report folder holds its `.tex` source, `File_Setup.tex` (packages and page style), `references.bib`, a `fig/` folder with the figures it uses (PDF only), and the compiled PDF.

| Folder | What is inside |
|---|---|
| [`v1_mnist/`](v1_mnist/README.md) | The MNIST final report |
| [`v1_fashion_mnist/`](v1_fashion_mnist/README.md) | The Fashion-MNIST final report |
| [`v1_mnist_fashion_mnist_report/`](v1_mnist_fashion_mnist_report/README.md) | The combined report on both datasets |
