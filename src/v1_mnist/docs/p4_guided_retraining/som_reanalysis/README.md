# Documents: SOM re-analysis (`src/v1_mnist/docs/p4_guided_retraining/som_reanalysis/`)

Written documents for this step: protocols written before the runs, results and explanations. Documents marked as protocols or pre-registrations are not edited after their runs; changes are logged in `docs/DEVIATIONS.md`. `MSP_ARM_ADDENDUM.md` adds the SOM re-analysis of the max-softmax arm; its outcome section is filled in when that run finishes.
