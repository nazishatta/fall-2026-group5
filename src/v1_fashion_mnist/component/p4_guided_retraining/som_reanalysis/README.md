# `som_reanalysis` (Fashion-MNIST)

The code for this step is shared by both datasets and lives in [`src/v1_mnist/component/p4_guided_retraining/som_reanalysis/`](../../../../v1_mnist/component/p4_guided_retraining/som_reanalysis/).
Fashion-MNIST runs it with the settings in [`../../configs/`](../../configs/), so nothing is copied here.

The step produces new maps on the retrained networks, compared before and after. Its results go to `outputs/v1_fashion_mnist/p4_guided_retraining/som_reanalysis/`.
