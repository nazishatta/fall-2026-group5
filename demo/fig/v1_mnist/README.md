# MNIST v1 Demo Figures (`demo/fig/v1_mnist/`)

This directory contains key figures, plots, and visualizations used in reports, presentations, and cookbooks for the MNIST v1 experiment:

- `confusion_matrix.png`: Confusion matrix heatmap for LeNet-5 predictions on the test set.
- `training_curves.png`: Training/validation loss and accuracy curves across epochs.
- `fc2_pca.png`: 2D PCA projection of the 84-dimensional `fc2` test set embeddings.
- `misclassified_examples.png`: Sample gallery of misclassified digits with predicted and true labels.
