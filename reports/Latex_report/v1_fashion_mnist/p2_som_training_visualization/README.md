# p2_som_training_visualization report (Fashion-MNIST)

LaTeX report for p2_som_training_visualization on Fashion-MNIST. Phase 2, SOM training and visualization: the SOM on the Fashion-MNIST embeddings and what it shows.

Source `som_cluster_error.tex`, packages in `File_Setup.tex`, references in `references.bib`. Figures in `fig/som_nnsom_training/`, `fig/cluster_analysis/` and `fig/error_pattern_analysis/`, copied from `outputs/v1_fashion_mnist/p2_som_training_visualization/`.

Build from this folder: `latexmk -pdf som_cluster_error.tex` (biber is run automatically). Build files are ignored by git; the compiled PDF is kept.
