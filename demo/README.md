# Demo files (`demo/`)

Files to show the project without running it.

| Folder | What is inside |
|---|---|
| [`project_pipeline/`](project_pipeline/README.md) | The project pipeline diagram (draw.io), shown at the top of the root README |
| [`interactive_plots/`](interactive_plots/README.md) | Interactive HTML charts of the official SOM, open in any browser |
| `figures/v1_mnist/phase_<n>_files/` | Empty folders kept for demo figures by phase (figures are PDF and live in `outputs/` and the reports) |
