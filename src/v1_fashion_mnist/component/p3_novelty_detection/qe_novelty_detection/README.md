# `qe_novelty_detection` (Fashion-MNIST)

The code for this step is shared by both datasets and lives in [`src/v1_mnist/component/p3_novelty_detection/qe_novelty_detection/`](../../../../v1_mnist/component/p3_novelty_detection/qe_novelty_detection/).
Fashion-MNIST runs it with the settings in [`../../configs/`](../../configs/), so nothing is copied here.

The step produces quantization-error novelty scores against the outside sets (to be chosen with the professor). Its results go to `outputs/v1_fashion_mnist/p3_novelty_detection/qe_novelty_detection/`.
