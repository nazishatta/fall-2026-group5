# `cnn_baseline_training` (Fashion-MNIST)

The code for this step is shared by both datasets and lives in [`src/v1_mnist/component/p1_model_training_baseline/cnn_baseline_training/`](../../../../v1_mnist/component/p1_model_training_baseline/cnn_baseline_training/).
Fashion-MNIST runs it with the settings in [`../../configs/`](../../configs/), so nothing is copied here.

The step produces the LeNet-5 trained on Fashion-MNIST with the MNIST recipe, its test metrics, and the fc2 embeddings of every split. Its results go to `outputs/v1_fashion_mnist/p1_model_training_baseline/cnn_baseline_training/`.
