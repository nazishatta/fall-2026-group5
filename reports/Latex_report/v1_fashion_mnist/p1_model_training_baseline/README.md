# p1_model_training_baseline report (Fashion-MNIST)

LaTeX report for p1_model_training_baseline on Fashion-MNIST. Phase 1, model training baseline: load and split Fashion-MNIST, train LeNet-5, save the embeddings.

Source `cnn_baseline_report.tex`, packages in `File_Setup.tex`, references in `references.bib`. Figures in `fig/cnn_baseline/` and `fig/data_pipeline/`, copied from `outputs/v1_fashion_mnist/p1_model_training_baseline/`.

Build from this folder: `latexmk -pdf cnn_baseline_report.tex` (biber is run automatically). Build files are ignored by git; the compiled PDF is kept.
